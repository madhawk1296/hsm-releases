# HSM

HSM gives Claude Code the tools to see, film, measure and compare web pages, so it builds sites that look and move like the ones you love.

- Download: [latest release](https://github.com/madhawk1296/hsm-releases/releases/latest)
- Website and guide: https://hsm-tools.vercel.app
- Help: [open an issue](https://github.com/madhawk1296/hsm-releases/issues/new). Include your HSM version and macOS version, and never post keys or private code.

This repository holds HSM's installers and support issues. HSM's source is private.
